RED OPERATIVA RELACIONAL - NEXA / SEPTIER

Inicio:
1. Ejecutar RedOperativaRelacional.exe.
2. Se abre un servidor local en 127.0.0.1 y el navegador entra a la plataforma.
3. Ingresar con el usuario autorizado de la plataforma.
4. Seleccionar Hoja Relacional si el navegador no queda ubicado automaticamente en ese modulo.

Carpetas:
- datos: base local, histories, adjuntos y salidas generadas por esta copia.
- app: frontend, plantillas y modulos locales necesarios para servir la interfaz.
- src: utilidades de procesamiento usadas por la plataforma.

Importante:
- Esta copia no modifica el deploy de Render.
- Para detener la app local, cerrar la ventana del ejecutable.
